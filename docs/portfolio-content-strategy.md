# Estrategia editorial del portfolio

## Posicionamiento

Manuel García-Llera se presenta como **Product Designer y Design Engineer especializado en sistemas de diseño, HCI e interacción humano-IA**. La investigación explica el criterio; el diseño estructura el sistema; el desarrollo demuestra que puede convertirse en producto.

No se presenta como tres perfiles independientes ni como prototipador de Figma. Figma, el código y la IA son evidencias del proceso.

## Jerarquía de cada caso

1. **Problema** — contexto, personas, restricciones y pregunta.
2. **Sistema** — principios, arquitectura, tokens, componentes, variantes y accesibilidad.
3. **Producto** — flujos y experiencia final, preferiblemente navegable.
4. **Implementación** — correspondencia diseño-código y límites reales.
5. **Evidencia** — validación, resultados, Figma, repositorio y créditos.

Cada caso debe distinguir con precisión **mi contribución** y **trabajo del equipo**.

## Jerarquía de acciones

- Tarjeta de home: **Explorar el caso**.
- Dentro del caso: **Recorrer el producto** y **Explorar el sistema**.
- Evidencias secundarias: **Abrir Figma**, **Consultar implementación** o documentación.

## Lenguaje visual

- Portfolio: blanco/negro, tipografía y espacio como estructura.
- Identidad de cada producto: contenida dentro de su panel visual.
- Movimiento: funcional y pausado; nunca decorativo ni imprescindible.
- Previsualizaciones: rectas, HD, una vista cada vez y con controles accesibles.

## Artículos

La publicación principal debe vivir en `/articulos` para acumular autoridad, enlaces y SEO en el dominio propio. Medium u otras redes pueden funcionar como canales de distribución mediante versiones resumidas o sindicadas con canonical hacia el original; no como archivo principal ni contenido embebido.

Líneas editoriales:

1. Sistemas de diseño que sobreviven al traspaso a código.
2. HCI, materialidad e interfaces hápticas/ópticas.
3. Integración responsable de IA en procesos de diseño.
4. Diseñar para roles, estados y sistemas complejos.
5. Experimentos de Something Human Lab.

No se mostrará “Blog” en navegación hasta que existan al menos tres piezas publicables.

## Selección inicial de casos

1. **Buy&Sell Marketplace** — caso de referencia para mostrar sistema de diseño, producto e implementación.
2. **LaLiga Hub de Clubes** — sistema complejo y multirol; se presenta como trabajo en evolución y con datos sintéticos, sin atribuir despliegue oficial.
3. **Coordination Hub** — experimento de interacción humano‑IA y coordinación verificable.
4. **The UX Union** — evolución visible desde identidad y primeras versiones hasta MVP implementado.

Los conceptos Fintech y Estadio permanecen fuera de la selección pública hasta disponer de un caso defendible. En The UX Union, las capturas locales HD son provisionales: los wireframes, el prototipo Hi‑Fi y el sistema mobile de Figma se incorporarán cuando estén disponibles sus enlaces compartidos, manteniendo clara la procedencia de cada evidencia.

## Estado y transparencia

- **Publicado**: caso suficientemente documentado y verificable.
- **En evolución**: producto real cuyo alcance o acabado continúa abierto.
- **Experimental**: investigación o prototipo que prueba una hipótesis.

Cada página debe declarar estado, contribución personal, colaboración y límites. Claude y Codex aparecen como herramientas o colaboradores del proceso cuando corresponda; la dirección, el criterio y la decisión final se atribuyen a Manuel.
